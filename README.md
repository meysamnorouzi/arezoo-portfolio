# Arezoo Jafary — Portfolio

A Next.js and Tailwind portfolio for Arezoo Jafary, Product Designer. Visual language follows [designleader.se](https://www.designleader.se/): dark editorial layout, Manrope headlines, muted-to-white contrast, and a four-page information architecture (Resume, Your Partner, Playbook, Contact).

Content is taken from `resume(arezoo.jafary)_238128.pdf`.

## Scripts

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home and selected work
- `/resume` — Background, education, skills
- `/partner` — How I work
- `/playbook` — Design process
- `/contact` — Message and links
- `/work/coffee-subscription`, `/work/pico-ai`, `/work/yogian` — Case stories
